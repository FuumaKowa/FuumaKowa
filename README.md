## Current Project

### 🏛️ [I-Madina Hall Booking System](https://github.com/FuumaKowa/Hall-Booking-System)

A full-stack reservation and management system built for hall operations at Nilai Harta Consultant.

The system allows customers to check hall availability, choose booking packages, receive estimated pricing, and submit reservation requests while giving managers the tools needed to control bookings and operational data.

**Key Features**

- Real-time booking and availability checks
- Hall and area selection
- Scheduling conflict prevention
- Server-side price and capacity validation
- Manager authentication
- Booking approval and rejection workflow
- Payment tracking
- Notifications
- Printable booking tickets
- Hall image and gallery management
- Persistent booking data
- Responsive customer-facing interface
- Offline venue assistant without requiring an external AI API

**Tech Stack**

`React 19` `TypeScript` `Vite` `Tailwind CSS` `Express` `Neon PostgreSQL` `Drizzle ORM` `Vercel Blob` `Vercel`

[Repository](https://github.com/FuumaKowa/Hall-Booking-System) • [Live Demo](https://hall-booking-system-psi.vercel.app)
